# Ravi Kumar — QA Portfolio

A single-page portfolio site built from my resume, showcasing my experience as a
Quality Assurance Engineer (Manual & API Testing) at Amazon.

**Live sections:** About · Skills & Tools · Experience · Education & Certifications
**Motion:** scroll-reveal animations, animated hero entrance, count-up metric numbers, animated crosshair mark — all respect "reduce motion" accessibility settings.

## Files

- `index.html` — page content
- `styles.css` — all styling (no build step, no dependencies)
- `script.js` — scroll-reveal, count-up numbers, and active nav highlighting (vanilla JS, no libraries)

## How to publish this on GitHub Pages (free hosting)

1. Create a new GitHub repository, e.g. `ravikumar-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the root of the repo
   (drag-and-drop on the GitHub website works fine, or use `git push`).
3. In the repo, go to **Settings → Pages**.
4. Under **Source**, select the `main` branch and `/ (root)` folder, then **Save**.
5. After a minute, GitHub will show your live URL:
   `https://<your-username>.github.io/ravikumar-portfolio/`
6. Add that link to your LinkedIn "Contact info" and resume.

## Editing later

Everything is plain HTML/CSS — open `index.html` in any text editor, update the
text between the tags, and re-upload. No build tools or installs required.
